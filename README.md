# 🧊 Nebula 3D

**The digital place where any idea becomes a 3D object.**

Nebula 3D is where you bring an idea and leave with a one-of-a-kind object. You don't need to be a 3D expert: you talk directly with the founders, shape the project together and get it printed.

## How it works
1. 💡 **Bring your idea**: a sketch, a photo, a reference or just a description
2. 💬 **Talk with the founders**: work on the details together, one to one
3. 🛠️ **Create something unique**: a custom project designed around you
4. 🖨️ **Get it printed in 3D**
